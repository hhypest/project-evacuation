# Переработка документации: DOC-01…DOC-05

Задача владельца от 2026-11-10 реализована в структуре документов: короткий вход, маршруты по задачам, основные источники правил, технические/дизайнерские руководства, архив и проверка ссылок. [Каталог](README.md) · [исходный план PR №39](maintenance/archive/documentation-plan-2026-11-10.md) · [свидетельства проверки](qa/documentation-rework-2026-11-10.md).

| Этап | Результат | Остаток |
| --- | --- | --- |
| DOC-01 | 49 исходных Markdown-файлов и каждый заголовок учтены; составлена карта источников/переносов и конфликтов | Состав расширяется при следующих переносах |
| DOC-02 | README на 94 строки; требования, roadmap, первый запуск и каталог отделены | Проверка удобства независимым читателем |
| DOC-03 | Карта архитектуры и справочники подсистем; правила кода/физики, команды, права и выпуск | Проверять инструкции при изменении tools/CI |
| DOC-04 | Вход по задачам дизайна, метрики и сборка, отдельные арт-история и архив лора, индексы ADR/QA | Открытые решения катсцен и художественная приёмка не закрыты |
| DOC-05 | Автоматическая проверка локальных ссылок, старых якорей и карты; сверка содержания и запуска описана в QA | Человеческий тест двух минут и первый графический запуск с Vulkan surface остаются открытыми |

Этапы выполнены последовательно в отдельных коммитах одного PR: это позволяет проверить целую структуру и все перенесённые ссылки вместе. Требования, ID и критерии игровых версий не менялись. Слияние документации не принимает игровые механики, канон или художественный результат повторно.

## Приёмка удобства

Владелец и участник, не выполнявший перенос, проверяют пять ответов: запуск, нужная проверка изменения, сборка камеры, источник канона и следующий незавершённый шаг. Цель — каждый ответ за две минуты, без устной подсказки. Записываются маршрут, время, ошибочные переходы и подсказки в [таблице QA](qa/documentation-rework-2026-11-10.md#приёмка-читателем).

Открытые пункты имеют отдельные статусы в [status](status.md#переработка-документации). Сопровождение новых документов — по [правилам обновления](maintenance/README.md).
