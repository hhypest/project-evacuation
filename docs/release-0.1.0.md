# Что осталось до 0.1.0

Сверено 2026-11-14 с [требованиями](requirements.md#механики-и-минимальная-готовность-к-010) и [критерием выхода](roadmap.md#010--скелет-игры-со-всеми-механиками). Из кода критический путь начинается с **SKL-11**, затем идёт **SKL-12**. После сборки нужны проверка на целевых платформах и ручная приёмка актуальной версии. [Состояние механик](status.md).

| Порядок | Задача | Что считать готовым |
| --- | --- | --- |
| 1 | **SKL-11. Атмосфера и тестовая опасность.** Добавить один звуковой или световой триггер и один участок опасности вне зоны обдумывания. Подключить его к восстановлению SKL-10. | После опасности игрок возвращается в последнюю допустимую точку. Камера остаётся решаемой, атмосфера оставляет игровые сигналы читаемыми. Проверить вход без сохранения, возврат со снимком JSON и повторный проход. |
| 2 | **SKL-12. Связать механики в один маршрут.** Выделить на полигоне последовательность «куб → кнопка → эмиттер → приёмник → цепь → гравитация и портал → выход». Связать её с сохранением и опасностью SKL-11. | Один маршрут с явным началом и концом. Пройти его минимум три раза подряд, включая полный reset и продолжение после перезапуска. Проверить потерю куба и повторный вход. |
| 3 | **SKL-09 и TD-08. Приёмка на актуальной сборке.** Сверить оба направления портала, быстрый куб, занятый выход, повороты и удерживаемый куб. Вручную пройти мувсет и «Резервный контур». | На экспортированной Windows-сборке с Vulkan маршрут пройден вручную. В отчёте указать GPU, драйвер, режим, p95 времени кадра и наблюдения по комфорту. Linux CPU-smoke в CI дополнить запуском экспорта на реальном Vulkan. |
| 4 | **Кандидат 0.1.0.** Собрать Windows и Linux из одного коммита с notices и manifest. Проверить новую игру, паузу, потерю фокуса, продолжение, завершение, reset и офлайн-запуск. | Архивы соответствуют хешам, CI зелёный. Для той же ревизии есть отчёт с платформами, версиями, тремя прохождениями и известными ограничениями. После приёмки владельцем можно тегировать выпуск. |

**SKL-10 уже реализован** в «Резервном контуре». JSON хранит контрольную точку камеры, восстановление работает при падении, потере куба и неустранимом сбое портала. Для выпуска осталось проверить восстановление на общем маршруте. Станция авангарда остаётся самостоятельной локацией снабжения и отдыха. [QA SKL-10 и FSR 2.2](qa/recovery-and-fsr-2026-11-13.md).

Фотореалистичная доводка и новый апскейлер идут в графическом потоке вертикального среза. Критерий готовности 0.1.0 требует работающих базовых механик в одном маршруте. [План графики и FSR 3.1](design/ambientcg-rendering-plan.md).
