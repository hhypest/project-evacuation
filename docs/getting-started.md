# Первый запуск

Результат: открыть меню и запустить «Единый полигон: все механики». Это прототип, а не готовая кампания. Для чтения документов установка движка не требуется.

## Что понадобится

Git, PowerShell 7, Windows или Linux x86_64 и GPU/драйвер с Vulkan. Редактор — **Godot 4.7.2 Standard** (`4.7.2.stable.official.ed1daf0bf`); точные архивы и SHA512 — в [toolchain.json](../tools/toolchain.json). Не использовать .NET-редактор как основание для C#. Jolt встроен, отдельное расширение не требуется. Blender нужен только для соответствующих задач контента.

## Установить и запустить

Откройте PowerShell 7 (`pwsh`) и выполните:

```powershell
git clone https://github.com/hhypest/project-evacuation.git
Set-Location project-evacuation
$env:GODOT_BIN = ./tools/setup.ps1 -SkipTemplates
& $env:GODOT_BIN --headless --path . --import
& $env:GODOT_BIN --path . --rendering-method forward_plus --rendering-driver vulkan
```

Установка проверяет SHA512 и сборку редактора; архивы остаются в игнорируемом `work/`. Шаблоны экспорта для запуска исходников не нужны. Для подготовки экспортов выполните `./tools/setup.ps1` без `-SkipTemplates`: полный комплект занимает около 1,4 ГБ. Все команды ниже запускаются из корня checkout, не из `tools/`.

Если официальный редактор нужной версии уже установлен, замените строку установки своим путём:

```powershell
$env:GODOT_BIN = 'C:\Tools\Godot_v4.7.2-stable_win64_console.exe'
& $env:GODOT_BIN --version
```

Путь выше — пример для Windows. На Linux задайте абсолютный путь к Linux-редактору. Нужен editor/console, а не export template. Ожидаемый вывод версии — `4.7.2.stable.official.ed1daf0bf`.

При обычном запуске игра заполняет экран без рамки в текущем разрешении монитора, сохраняя режим рабочего стола. Для оконного запуска добавьте `-- --windowed` к команде Godot или `evacuation.exe`. Текстовый журнал создаётся автоматически в [папке `logs`](performance.md#журнал-сессии) рядом с игрой.

## Проверить первый результат

В меню выберите мышью либо Enter «Единый полигон: все механики». Проверьте движение, обзор и Esc: на паузе мышь свободна, после явного продолжения — захвачена. В редакторе можно открыть [project.godot](../project.godot) через Project Manager и нажать F5; F6 запускает открытую `src/bootstrap/main.tscn`.

Следующий пункт, **«Резервный контур»**, открывает отдельную головоломку с балластом, резервным питанием и оптической блокировкой. Перед первым проходом ориентируйтесь по табличкам в камере.

В главном меню и паузе есть **«Камера и подсказки»**. Можно настроить вертикальный угол обзора 55–90°, чувствительность мыши 25–200% и время поворота на 90° при смене гравитации от 0,25 до 1 с. Кнопка **«Готово»** или Esc применяет изменения и возвращает в предыдущее меню. Параметры сохраняются в `user://camera.cfg` отдельно от контрольной точки.

| Действие | Управление |
| --- | --- |
| Движение, обзор | WASD, мышь |
| Бег / медленная ходьба | Shift / Alt; без выносливости |
| Прыжок / приседание | Space / Ctrl; Ctrl в воздухе — duck-jump |
| Взять / отпустить куб | E, дальность 3 м. Оба игровых куба (5 и 10 кг) можно взять |
| Точная постановка | С кубом посмотреть на опору: силуэт и «E — поставить» показывают, где закрепится куб |
| Настенная кнопка / бросок | E в пределах 2,2 м / ЛКМ с кубом |
| Лестница | W/S вверх/вниз, Space — оттолкнуться |
| Вода | Space вверх/выход на берег, Ctrl вниз |
| Пауза / перезапуск | Esc / R |
| Показатели / запись CSV | F3 / F4, подробнее [профилирование](performance.md) |

Меню паузы позволяет вернуться к выбору уровней и выйти. Захват куба сохраняется на паузе, перезапуск его очищает. После потери фокуса игра требует явного продолжения. Удержанную через паузу/перезапуск клавишу нужно отпустить и нажать снова; движение мыши из меню не переносится в игру.

Дальше: [сценарии семи отсеков](testing.md#уровни-для-ручной-проверки), [проверки изменения](development/checks.md), [сборка дистрибутива](development/release.md). Комната **07 «Свет и тени»** находится прямо в конце коридора: E переключает рубильники движения, точечного света, прожектора и теней; [порядок сравнения](testing.md#комната-07-свет-и-тени). Игрок проходит через порталы, в том числе с удерживаемым кубом.

## Масштабирование 3D

Откройте **Камера и графика → Масштабирование 3D** в меню или на паузе. **Нативное** — режим по умолчанию. **FSR 2.2 · Качество** рассчитывает основной 3D-вид в ⅔ разрешения по каждой оси. HUD и внутренние буферы порталов используют свои прежние разрешения. Выбор применяется сразу и хранится в локальном `graphics.cfg`.

## Сохранения

Игра записывает вход в камеру в папку `saves` рядом с исполняемым файлом или в корне проекта при запуске из Godot. В «Резервном контуре» включите резерв, подойдите к станции авангарда в служебном зале, наведите прицел на консоль и нажмите **E** со свободными руками. Экран станции подтвердит запись.

В следующем запуске выберите **«Продолжить с контрольной точки»**. Со станции загрузятся её позиция и включённый резерв, экранный куб вернётся на опору в луче, а балласт на основную плиту. Завершение камеры отмечается в меню. **R** начинает текущую попытку с входа, сохранённая точка остаётся доступна из главного меню. Падение за пределы уровня, потеря куба и неустранимый сбой портала автоматически возвращают к последней контрольной точке текущей камеры. Если станция ещё не сохранена, игра возвращает к входу.

## Если запуск не удался

| Признак | Действие |
| --- | --- |
| `setup.ps1` не запускается | Открыть PowerShell 7, перейти в корень репозитория; из bash использовать `pwsh` |
| Несовпадение версии или SHA512 | Не продолжать с другим редактором; сверить lock и путь, сохранить сообщение для диагностики |
| Первый импорт зависает в окне | Выполнить headless-импорт из инструкции выше: он сжимает текстуры на CPU; кэш `.godot/` не коммитить |
| Не инициализируется Vulkan | Проверить поддержку GPU и драйвер; OpenGL/D3D12 не подтверждают поддерживаемый запуск |
| Экспорт требует templates | Установить полный комплект через setup; шаблоны должны совпадать с редактором |

В [сообщении об ошибке](../CONTRIBUTING.md#8-сообщение-об-ошибке) укажите команду, ОС, версию Godot и журнал; для графики — GPU/драйвер. Успешный headless-импорт не доказывает графический запуск.
