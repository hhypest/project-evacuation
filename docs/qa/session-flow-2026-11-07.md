## Прерванная ручная проверка

Windows-экспорт открыт как обычное приложение, Enter действительно запускает сессию. Затем для проверки потери фокуса активировано другое существующее окно. При попытке вернуться в игру пользователь остановил управление окнами физическим **Esc**. После этого действия в окна больше не отправлялись.

Не считать завершёнными: нативный цикл «потеря фокуса → возврат без auto-resume → явное продолжение», физический обзор мышью, restart/возврат в меню и штатный выход в экспортированной версии. Наличие автоматических тестов и исходного GPU-smoke не подменяет эти пункты. Запущенное окно игры оставлено пользователю.

Перед закрытием SKL-01 выполнить оставшийся сценарий в Windows-сборке:

1. Начать сессию мышью и клавиатурой, проверить обзор и освобождение курсора по Esc.
2. Удерживать W/Space, открыть паузу; после продолжения убедиться в отсутствии старых действий. Сейчас движение не реализовано, состояние проверяется по автоматическим тестам/будущему потребителю ввода.
3. Переключить активное окно и вернуться. Игра должна остаться на паузе; продолжить явно.
4. Перезапустить из паузы и во время сессии; убедиться в новой комнате/камере без накопленного поворота.
5. Вернуться в главное меню, начать новую сессию и выйти кнопкой/закрытием окна.

## Воспроизведение автоматических проверок

PowerShell 7, из корня репозитория, `GODOT_BIN` указывает на закреплённый редактор:

```powershell
./tools/check.ps1
& $env:GODOT_BIN --path . --rendering-driver vulkan --script tools/gpu_smoke.gd
./tools/export.ps1
```

GPU-проверка создаёт собственное окно и выполняет тестовые действия; запускать её при готовности пользователя к такой проверке. Кадры по умолчанию — `work/gpu_smoke.png`, `work/gpu_smoke-menu.png`, `work/gpu_smoke-pause.png`. Логи headless, GPU и реального экспорта оцениваются отдельно. Состояние CI и ссылка на PR фиксируются в GitHub; локальный успех не выдаётся за удалённый.
