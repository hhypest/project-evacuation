# Профилировщик и импорт 2K — 2026-11-09

## Изменение

По запросу владельца к моделям четырёх устройств добавлены диагностическая панель F3, запись CSV по F4 и обратимые профили импорта Source/2K. Диагностика собирает данные в Infrastructure, передаёт типизированный `ProfilerSample` в Presentation и связывается в Bootstrap. Domain и правила сессии не изменены. Панель относится к средствам разработки, не к финальному диегетическому UI.

Профиль хранится в `DeviceTextureSettings`; инструмент `tools/set_texture_quality.ps1` проверяет движок и весь комплект до записи, меняет размер импорта 12 карт, выполняет импорт и проверяет реальные размеры. Исходники сохраняются. При неудаче настройки и кэш восстанавливаются. Текущее состояние для PR — Source.

## Проверки

Среда: Godot `4.7.2.stable.official.ed1daf0bf`, Vulkan 1.4.351, Forward+, Jolt, RTX 4070 Ti SUPER, 1280 × 720.

| Проверка | Результат |
| --- | --- |
| `tools/check.ps1` | 237/237, 121 скрипт; типы, слои, runner и все suite |
| Контракты профилировщика | FPS/p95, отказ NaN/пустого окна, скрытый неактивный узел, UTF-8 CSV с запятыми в имени уровня, отказ недоступного пути |
| Импорт 2K | 12/12 импортированных `Texture2D` имеют размер 2048 × 2048 |
| Возврат Source | 12/12: цвет/нормали 4096, metallic/roughness 2048; исходники не изменены |
| GPU-smoke профилировщика | Реальные GPU-времена и память; F3/F4 не меняют паузу, захват мыши и ограничения фокуса; скрытая панель продолжает CSV; файл читается после остановки |
| Общий `tools/gpu_smoke.gd` | Пройден после подключения диагностики: сессия, ввод, движение, перенос, устройства, луч и гравитация |
| Порталы | Найдены root и два SubViewport; перезапуск с удалением и созданием viewport прошёл |
| Выпускной Windows-экспорт | Собран; headless-запуск без флага не создаёт панель, с `--profile` выдаёт `PROFILER_READY`; оба завершаются без ошибок |

Прогон с CSV: `godot --path . --script tools/profiler_smoke.gd -- --capture work/profiler.png --report work/profiler.csv`. Визуально просмотрен кадр панели. Приёмка управления выполнялась событиями ввода в GPU-smoke; ручной пользовательский прогон не выполнялся.

## Короткое сравнение памяти

Одинаковый старт полигона, окно 1280 × 720, два отдельных запуска. Оценка `Performance.RENDER_TEXTURE_MEM_USED` при прохождении:

| Импорт | Байты | MiB |
| --- | ---: | ---: |
| Source | 281 513 472 | 268,47 |
| 2K | 180 850 176 | 172,47 |
| Разница | 100 663 296 | 96,00 |

Это оценка памяти текстур Godot, не вся VRAM. Короткие записи подтверждают переключение ресурсов; прогретый длительный тест FPS/порталов не выполнялся. Физика осталась 60 Гц. Профиль Source восстановлен перед завершением.
