# SKL-04/05: устройства, цепи и логика, 0.0.5-dev

Дата: 2026-11-08. Основание — main после PR №5 (SKL-03). Реализованы SKL-04 (модель устройств, напольная и настенная кнопки, дверь) и SKL-05 (цепи, AND/OR/NOT, задержка, защёлка). Эмиттер, гравитация, порталы и сохранения ещё впереди; приёмка 0.1.0 не заявляется.

## Среда и область

Godot 4.7.2 Standard (`ed1daf0bf`), встроенный Jolt, физика 60 Гц. Проверки выполнены в облачной Linux-среде: headless для тестов и Vulkan через программный llvmpipe для GPU-smoke. Проверка на реальном GPU владельца — в разделе GPU-smoke. Новых внешних зависимостей и ассетов нет. Решение и порядок тика — [ADR-0008](../adr/0008-device-network.md).

## Полигон устройств

В `foundation_lab.tscn` добавлен узел `PuzzleLab`, построенный `PuzzleLabBuilder` из примитивов: стена с четырьмя отсеками за стартовой зоной. Управление: E на настенной кнопке в пределах 2,2 м нажимает её; если в руках куб, E по-прежнему отпускает куб.

| Отсек | Устройства | Ожидаемое поведение |
| --- | --- | --- |
| 1. Плита | Плита 8/6 кг, два куба по 5 кг, дверь | Один куб не открывает; два куба (в том числе стопкой) или игрок открывают; снятие закрывает. Дверь не закрывается на кубе в проёме |
| 2. Таймер | Кнопка TIMED 4 с → дверь | Открыта 4 с после нажатия, повторное нажатие перезапускает отсчёт |
| 3. Переключатель | Кнопка TOGGLE → дверь | Каждое нажатие меняет состояние |
| 4. Логика | Кнопки S/R (0,2 с) → защёлка → задержка 1 с → AND (с переключателем отсека 3) → дверь | Дверь открывается через 1 с после S только при включённом переключателе; R сбрасывает |

Цвета и надписи на устройствах — техническое представление по ADR-0006 (янтарный — активно, тёмный — нет), не финальные ассеты.

## Результаты

Полный `tools/check.ps1` прошёл: **154/154** за 97 058 мс (68 unit, 8 contract, 58 integration, 20 regression). Проверены типы/оформление 77 GDScript и границы слоёв 52 production-скриптов. Ошибок/предупреждений нет. Новые проверки: 22 unit `PuzzleNetworkTests` и 12 интеграционных `PuzzleDeviceTests`; прежние 119 тестов не изменились и проходят.

| Сценарий | Свидетельство |
| --- | --- |
| Валидация определения | Пустые/повторные ID, неверная арность, неизвестный/собственный источник, потребитель как источник, неверные пороги/время, мгновенная петля — отказ сборки |
| Цикл через DELAY/LATCH | Допустим и собирается |
| Плита: гистерезис и антидребезг | Пороги 8/6 кг, settle 3 тика: включение только после устойчивой нагрузки, удержание между порогами, разрыв контакта на 2 тика не отпускает, NaN = 0 |
| Настенная кнопка | TIMED выключается ровно через заданное число тиков, повтор перезапускает; TOGGLE переключается |
| Логика | Полные таблицы AND/OR/NOT; цепочка из нескольких узлов вычисляется за один тик |
| Задержка | Импульс в 1 тик через задержку 0,1 с (6 тиков при 60 Гц): трасса выхода `[0,0,0,0,0,1,0,0]` |
| Защёлка | Set запоминает, reset очищает, при одновременных сигналах побеждает reset |
| Порядок и тики | Перестановка определений не меняет результат; повтор/откат tick отклоняется |
| Снимок / reset | Восстановление снимка воспроизводит последующие выходы; частичный снимок отвергается |
| Jolt: стопка | Два куба 5 кг друг на друге открывают плиту 8 кг; снятие верхнего закрывает |
| Jolt: игрок | Игрок 80 кг на плите открывает её |
| Jolt: дверь и куб | Куб в проёме удерживает дверь открытой; скорость куба < 1 м/с, смещение < 0,3 м за 1,5 с; после удаления куба дверь закрывается |
| E: кнопка / перенос | E по кнопке не захватывает куб; E по кубу по-прежнему захватывает |
| Jolt: таймер / переключатель | Дверь открыта 4 с и закрывается после; toggle открывает и закрывает |
| Jolt: цепь логики | S → защёлка → задержка 1 с → AND (с включённым переключателем) → дверь: через 0,5 с выход ещё закрыт, через 1,3 с открыт; reset камеры возвращает защёлку и переключатель в исходное состояние |

### Независимость от частоты кадров

Integration suite повторён с `--fixed-fps 30` и `--fixed-fps 144` (физика 60 Гц): **58/58** в обоих прогонах, без ошибок/предупреждений.

### GPU-smoke

`tools/gpu_smoke.gd` расширен шагом устройств: после переноса куба fixture ставит игрока перед кнопкой TIMED, реальное событие E проходит через SessionInput и открывает дверь; сохраняется кадр `work/gpu_smoke-devices.png`. В облаке на Vulkan/llvmpipe получен `GPU_SMOKE_PASSED ... devices=button/door`; кадр просмотрен. **Реальный GPU, 2026-11-08:** владелец запустил `tools/gpu_smoke.gd` на Windows, NVIDIA GeForce RTX 4070 Ti SUPER, Vulkan 1.4.351, Forward+, Jolt — получен `GPU_SMOKE_PASSED driver=vulkan gpu=NVIDIA GeForce RTX 4070 Ti SUPER carry=grab/hold/throw devices=button/door/beam gravity=field/wall-walk …`; кадры меню, двери, луча и поля просмотрены и совпадают с облачными. Владелец также прошёл оба испытания и полигон вручную.

## Ограничения

- Направление «вверх» для стопок на плите — мировое +Y; поддержка изменённой гравитации — в SKL-07.
- Масса игрока для плит задаётся профилем `default_puzzle.tres` (80 кг), а не физикой контроллера.
- Состояние сети пока не записывается в JSON; снимок домена подготовлен для SKL-10.
- Ручная проверка полигона в экспортированной сборке не выполнялась.
