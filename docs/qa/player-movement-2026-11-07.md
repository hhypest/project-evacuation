# SKL-02: полигон и мувсет 0.0.3-dev

Дата: 2026-11-07. SKL-01 принята владельцем и слита в main через PR №1 (`1bb71ef`). Этот отчёт относится к следующему изменению, а не к завершению версии 0.1.0.

## Область и среда

Godot 4.7.2 Standard, build `ed1daf0bf`; явный Vulkan/Forward+, Jolt, физика 60 Гц. Локальная GPU-проверка: Windows x86_64, NVIDIA GeForce RTX 4070 Ti SUPER, Vulkan 1.4.351. Новых внешних зависимостей и ассетов нет.

Реализованы движение/стрейф, медленная ходьба, разгон/торможение, прыжок и air control, приседание/duck-jump, ступени/склоны/низкий проход, лестница, плавание/погружение/выход из воды, перенос опорой и ограниченное толкание. Ввод и поколения сессии используют существующий путь SKL-01.

## Автоматическая приёмка

Всего **72 проверки**: 27 unit, 4 contract, 26 integration, 15 regression. `tools/check.ps1` также проверяет 40 GDScript, 24 production-скрипта по слоям, оформление и отрицательные случаи runner. Все эти проверки прошли локально без ошибок/предупреждений.

| Сценарий | Наблюдение / критерий |
| --- | --- |
| Скорость по прямой | 6,000 м/с, позиция после контрольного разгона `(0, ~0, 4.207064)` |
| Ходьба / отпускание | 2,5 м/с по Shift, после отпускания планарная скорость < 0,02 м/с |
| Обычный прыжок | Пик около 0,951 м при целевом профиле 0,9 м; возвращается на пол |
| Ступени | Подъём на площадку 1 м без прыжка, возвращение по ступеням на пол |
| Низкий проход | Стоя остановка до входа; crouch проходит, вставание под потолком отвергается; после выхода разрешено |
| Пологий/крутой склон | Подъём по 15°; 65° не превращается в доступную лестницу |
| Duck-jump | Достигнут уступ 1,35 м, выше обычного прыжка; конечная высота около 1,3509 м |
| Стена | Планарное скольжение вдоль препятствия без проникновения |
| Лестница | Подъём/спуск, прыжок от поверхности и выход на верхнюю площадку проверены отдельно |
| Вода | Подъём и погружение; выход на берег с возвратом обычной опоры |
| Движущаяся опора | Игрок переносится по X, сохраняет опору и положение относительно платформы в допуске 0,3 м |
| Предметы | Куб 20 кг сдвигается более 0,25 м за контрольную секунду, скорость ограничена; куб 1000 кг не запускается той же силой |
| Диагональ / air strafe | Диагональная скорость не выше 6 м/с; направление скорости изменяется в воздухе |
| Сессия | Исходные проверки меню/фокуса/паузы/restart/поколений сохраняются |

Integration suite дополнительно выполнена при `--fixed-fps 30` и `--fixed-fps 144`: **26/26** в обоих случаях. Скорость, пик прыжка и итог подъёма по ступеням совпали в контрольных выводах; физика оставалась 60 Гц. Это проверка render cadence, не обещание побитовой идентичности разных платформ.

При ранних прогонах обнаружены и исправлены застревание округлённой капсулы на ступени и повторный захват верхней части лестницы. Предупреждение переполнения worker jobs Jolt в неограниченном ускоренном тесте решено уступкой планировщику в тестовом guard, а не сменой backend/подавлением предупреждений.

## GPU и экспорт

Обновлённый `tools/gpu_smoke.gd` прошёл на реальном Vulkan: запуск через меню, D/W, прыжок/duck-jump, camera follow, обзор мышью, пауза/освобождение ввода, программные уведомления фокуса, restart и close_requested. Результат — `GPU_SMOKE_PASSED`, exit 0. Кадр полигона просмотрен. В этом сценарии события ввода подаются средствами Godot; он не выдаётся за полное ручное прохождение.

Windows и Linux release-экспорты собраны. Windows-экспорт отдельно открыт как обычное приложение, подтверждены главное меню, загрузка/изображение полигона и закрытие через Alt+F4. Длительное удержание физических клавиш и субъективное ощущение всех зон не объявляются измеренными этим оконным smoke. Linux Vulkan локально не проверен; состояние удалённого CI отражается в проверках PR.

## Дальнейшая работа

Параметры — собственный исходный профиль, точное совпадение с HL1 не доказано. SYS-05 предусматривает дополнительные измерения и настройку ощущений. Смена гравитации, порталы и перенос предметов пока не реализованы и относятся к следующим задачам. Финальный диегетический UI появится согласно ADR-0004; JSON-сохранения — согласно ADR-0003.

Для воспроизведения: `tools/check.ps1`, integration suite с render cadence 30/144, `tools/gpu_smoke.gd` на реальном GPU и `tools/export.ps1`. В полигоне используются WASD, Shift, Space, Ctrl, мышь, Esc и R; зоны подписаны техническими 3D-метками.
