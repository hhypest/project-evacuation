# SKL-06: эмиттер, луч, перекрытие и приёмник, 0.0.6-dev

Дата: 2026-11-08. Основание — main после PR №14 (SKL-04/05). Реализована SKL-06 и слита через PR №15. Гравитационные зоны, порталы и сохранения ещё впереди; приёмка 0.1.0 не заявляется.

## Среда и область

Godot 4.7.2 Standard (`ed1daf0bf`), встроенный Jolt, физика 60 Гц. Проверки выполнены в облачной Linux-среде: headless для тестов и Vulkan через программный llvmpipe для GPU-smoke. Реальный GPU для этой задачи пока не проверялся. Новых внешних зависимостей и ассетов нет. Правила луча и порядок тика — дополнение SKL-06 в [ADR-0008](../adr/0008-device-network.md).

Объём 0.1.0 по Architecture §7: один канал, прямой луч до первой преграды. Отражения, разветвления, пропускание луча через порталы и цветовое смешивание не входят.

## Полигон: отсек 5 «Луч»

У правого края полигона устройств (если стоять лицом к стене с отсеками 1–4) — перегородка с дверью. Перед ней на высоте 0,6 м эмиттер на стойке светит через отсек в приёмник (около 9,2 м). Переключатель на перегородке (E) питает эмиттер. Приёмник открывает дверь перегородки. Рядом лежит куб 5 кг (`lab.cube.small_c`): поставленный на пол в створ луча, он его перекрывает; игрок в створе тоже перекрывает луч.

| Параметр | Значение |
| --- | --- |
| Дальность эмиттера | 20 м |
| Канал | 0 |
| Конус приёма | 30° от нормали лицевой стороны |
| Антидребезг приёмника | 3 тика (50 мс) на включение и на выключение |
| Маска преград | мир/двери, кубы/пропсы, игрок |

Корпуса, линза и кольцо — техническое представление: циан — игровая оптика, янтарь — питание/сигнал (ADR-0006), не финальные ассеты.

## Результаты

Полный `tools/check.ps1` прошёл: **169/169** за 104 024 мс (74 unit, 8 contract, 67 integration, 20 regression). Проверены типы/оформление 81 GDScript и границы слоёв 55 production-скриптов. Ошибок/предупреждений нет. Новые проверки: 6 unit и 9 интеграционных `BeamDeviceTests`; прежние 154 теста проходят.

| Сценарий | Свидетельство |
| --- | --- |
| Попадание и антидребезг | Прямое попадание от запитанного эмиттера включает приёмник после settle; перекрытие на 1 тик не выключает, длительное — выключает |
| Отказы правила | Не принимаются: 60° при конусе 30°, сзади, NaN, выключенный эмиттер, другой канал, не-эмиттер, неизвестный эмиттер, попадание, адресованное другому устройству |
| Конус | 25° при конусе 30° принимается |
| Валидация | Отрицательный канал, конус 120° — ошибка сборки; цепь «приёмник → НЕ → эмиттер» допустима |
| Jolt: без питания | Луч не показан, приёмник и дверь выключены |
| Jolt: включение | E по переключателю запитывает эмиттер; длина трассировки 9,175 м совпадает с расстоянием до лицевой стороны приёмника (допуск 5 см); приёмник открывает дверь |
| Jolt: куб | Куб в середине створа обрывает луч на 4,15 м, приёмник выключается, дверь закрывается; после удаления куба попадание восстанавливается |
| Jolt: игрок | Игрок в створе перекрывает луч |
| Jolt: угол | Приёмник, повёрнутый на 60°, по-прежнему задет лучом (9,05 м), но попадание отвергнуто |
| Jolt: выключение / reset | Повторное E снимает питание, луч скрыт, приёмник выключается; reset камеры возвращает эмиттер и приёмник в исходное состояние |

### Независимость от частоты кадров

Integration suite повторён с `--fixed-fps 30` и `--fixed-fps 144` (физика 60 Гц): **67/67** в обоих прогонах, без ошибок/предупреждений.

### GPU-smoke

`tools/gpu_smoke.gd` после шага кнопки/двери ставит игрока к переключателю луча, реальное событие E запитывает эмиттер, приёмник открывает дверь; сохраняется кадр `work/gpu_smoke-beam.png`. В облаке на Vulkan/llvmpipe получен `GPU_SMOKE_PASSED ... devices=button/door/beam`; кадр просмотрен: циановый луч доходит до светящегося кольца приёмника. **Проверка на реальном GPU (Windows) ещё не выполнена.**

## Ограничения

- Поворот приёмника в тесте выполнен присваиванием трансформа статического тела в fixture; в игре приёмники не двигаются.
- Видимый луч — тонкий параллелепипед без свечения в объёме и звука попадания; звук и финальный вид — ART/SYS.
- Состояние приёмников и эмиттеров пока не записывается в JSON (SKL-10).
- Ручная проверка полигона в экспортированной сборке не выполнялась.
