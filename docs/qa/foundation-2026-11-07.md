## Воспроизведение

PowerShell 7, из корня репозитория:

```powershell
$env:GODOT_BIN = ./tools/setup.ps1
./tools/check.ps1
& $env:GODOT_BIN --path . --rendering-driver vulkan --script tools/gpu_smoke.gd
./tools/export.ps1
```

`tools/check.ps1` отказывает не только по ненулевому exit code, но и по сообщениям ошибок/предупреждений Godot: некоторые ошибки импорта могут сопровождаться нулевым кодом. Снимок GPU-smoke по умолчанию находится в игнорируемом `work/gpu_smoke.png`.
