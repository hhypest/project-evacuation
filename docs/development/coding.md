# Правила кода

Обязательны для собственного GDScript. Границы слоёв — в [архитектуре](../../Architecture.md), профиль и измерения физики — в [правилах физики](physics.md).

## 4. GDScript

- Явные типы у переменных, констант, параметров, результатов методов и параметров сигналов, включая callbacks и тесты. Для процедур — `-> void`.
- Коллекции типизированы: `Array[DeviceState]`, `Dictionary[StringName, bool]`. Для составного контракта использовать DTO, не произвольный словарь.
- Именование: файлы/функции/поля — `snake_case`, классы — `PascalCase`, константы — `UPPER_SNAKE_CASE`.
- `Variant`, сырые JSON/ConfigFile/raycast-словари допустимы только внутри проверяющего адаптера. Проверять тип, диапазон, обязательные поля и `null`; внутрь передавать типизированный результат или ошибку.
- Не использовать строковые `call`, `get`, `set` и поиск методов вместо известного контракта. Если сторонний API вынуждает динамический доступ, изолировать его в адаптере и объяснить.
- Включить предупреждения нетипизированных объявлений и unsafe-операций; собственный код принимается без необоснованных предупреждений. Локальное подавление — только для неизбежной границы API с пояснением и проверкой.
- Не подавлять ошибки всего файла и не использовать `assert` как единственную обработку ошибочного файла сохранения: release должен безопасно обработать ожидаемый отказ.
- Настраиваемые величины движения/физики хранятся в профилях. Указывать единицы; не переносить числа из Source/GoldSrc без перевода и проверки.
- Не добавлять C#/C++ в игровую логику. Шейдеры Godot допустимы как графические ресурсы, не как альтернативное место правил головоломки.


Внешний форматтер/линтер пока не вводится. `.editorconfig` фиксирует табы GDScript, UTF-8, завершающий перевод строки и отсутствие хвостовых пробелов; `tools/check.ps1` проверяет базовое оформление и типы всех скриптов. `tools/check_layers.ps1` проверяет зависимости лексически; он дополняет ревью. Главный источник проверки типов — закреплённый Godot 4.7.2. Общее описание возможностей — [статическая типизация GDScript](https://docs.godotengine.org/en/4.7/tutorials/scripting/gdscript/static_typing.html).
