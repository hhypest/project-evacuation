# ADR-0003: JSON как формат сохранения прогресса

- Статус: принято. Первый этап SKL-10 реализован
- Дата: 2026-11-07
- Задачи: SKL-10, SYS-04, CMP-04

## Контекст и решение

Прогресс хранится в UTF-8 JSON в папке `saves` рядом с исполняемым файлом игры. При запуске исходного проекта папка создаётся в его корне. Папку создаёт первая запись. Если каталог недоступен, меню показывает ошибку сохранения.

Версия схемы 1 задаёт четыре поля.

| Поле | Значение |
| --- | --- |
| `schema_version` | Целое число 1 |
| `game_version` | Версия сборки игры |
| `level_id` | Стабильный ID уровня из каталога |
| `checkpoint_id` | `entry`, точка входа из сцены |

Запись происходит после успешного открытия камеры из меню. При загрузке игра находит уровень по стабильному ID и открывает его со стартовым состоянием сцены. Следующие этапы SKL-10 вводят станции, сохранение дискретного прогресса и восстановление после гибели или потери предмета.

## Граница архитектуры

Application определяет типизированные `SaveSnapshot`, `SaveResult` и порт `SaveRepository`. Infrastructure отвечает за файлы, JSON и проверку структуры. Идентификаторы задаются в контенте. Экземпляры узлов, ресурсы и дескрипторы физики остаются в рантайме. Настройки управления, графики и звука находятся вне этой схемы.

## Проверка и последствия

Адаптер записывает временный файл в `saves`, закрывает и перечитывает его для проверки, затем публикует под новым именем `checkpoint-*.json`. Переименование в новое имя сохраняет предыдущее исправное поколение на Windows. Повторная запись той же точки в той же версии сборки использует уже записанный файл. Чтение пропускает временные файлы и ищет последнюю исправную запись при повреждении JSON. Если последняя запись использует более новую схему, адаптер прекращает загрузку и оставляет её на диске.

Первый этап проверяет чтение и запись, повреждённый JSON, неверные типы, недоступный путь, прерванную запись и открытие камеры после загрузки из меню. В SYS-04 запланированы миграции, проверки устойчивости записи на целевых ОС и политика хранения поколений.
