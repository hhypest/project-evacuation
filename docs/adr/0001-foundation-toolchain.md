# ADR-0001: Начальная среда и границы проекта

- Статус: принято для подготовительного этапа
- Дата: 2026-11-07
- Задачи: FND-01–FND-05

## Контекст

Репозиторий создан пустым. Требования фиксируют Godot 4.7, типизированный GDScript, Vulkan и Jolt. Нужна воспроизводимая основа, на которой следующие механики можно реализовывать и проверять без смены архитектуры.

## Варианты

1. Плавающая версия редактора и настройки проекта по умолчанию: быстрее начать, но результаты и физика могут незаметно меняться.
2. Зафиксированная официальная сборка и явный выбор backend: требует проверки дистрибутивов, зато локальные и CI-проверки имеют одну базу.

## Решение

Использовать Godot 4.7.2 Standard, CLI build `4.7.2.stable.official.ed1daf0bf`, соответствующие Windows/Linux x86_64 templates. Версии и официальные SHA512 архивов фиксируются в `tools/toolchain.json`. `tools/setup.ps1` скачивает и проверяет их; игровые зависимости не требуют платных инструментов.

Forward+ использует явно выбранный Vulkan, fallback на D3D12/OpenGL выключен. Jolt выбран строкой `Jolt Physics`, частота — 60 Гц. Headless допустим для CPU-проверок и явно не считается свидетельством Vulkan.

Собственный код разделён на Domain/Application/Infrastructure/Presentation/Bootstrap. Начальный домен управляет жизненным циклом сессии; проверка runtime получает DTO из адаптера. Тестовый полигон — примитивная сцена с опорой и динамическим кубом. В нём нет заявлений о готовности мувсета или игровых головоломок.

Тестовый runner написан на GDScript; подготовительные команды — PowerShell 7, также доступный на Linux CI. Внешний тестовый фреймворк и форматтер не добавлены. Формат кода задаёт `.editorconfig`; parse/type gate и проверка пробельного оформления выполняются до принятия изменения.

## Последствия

Автоматическая установка с export templates скачивает около 1,4 ГБ архивов и использует дополнительное место для распаковки. Для CPU-проверок есть `-SkipTemplates`. Крупные архивы/кэши/бинарники исключены из Git и экспорта.

Проверка слоёв — лексический предохранитель, не формальное доказательство Clean Architecture. Нужны ревью и осмысленные тесты. Обновление Godot требует обновить lock, валидатор runtime, тесты, notices и повторно проверить физику/Vulkan/экспорты.

## Проверка и пересмотр

`tools/check.ps1` проверяет типы всех скриптов, границы слоёв, 13 поведенческих проверок и отрицательные случаи runner. `tools/gpu_smoke.gd` требует реальный Vulkan и сохраняет кадр. `tools/export.ps1` собирает оба desktop-экспорта; запуск каждого на целевой ОС проверяется отдельно.

Результаты среды и ограничения фиксируются в `docs/qa/foundation-2026-11-07.md`. Новый patch-релиз рассматривается при исправлении релевантного дефекта, не устанавливается автоматически.
