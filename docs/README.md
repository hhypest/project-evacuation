## Как читать статусы

- **Требование** задаёт обязательный результат; не доказывает его реализацию.
- **Принятое решение** задаёт способ работы; актуальность и замены указаны в индексе ADR.
- **Реализовано** означает наличие изменения; проверка на целевом ПК и приёмка могут оставаться открытыми.
- **Предложение / ориентир** проверяется на срезе и не становится принятым при редактуре.
- **QA / архив** описывает определённый запуск или прежнюю редакцию; не является новым поручением.
